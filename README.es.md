# TagEX — Etiquetas de envío

[English](README.md) · [Português (Brasil)](README.pt-BR.md) · **Español** · [简体中文](README.zh-Hans.md)

Aplicación de código abierto para crear etiquetas en papel o rollos térmicos. Permite introducir datos, importar XML de NF-e brasileña y buscar en carpetas con el servicio local opcional.

- Interfaz en inglés por defecto, portugués, español y chino simplificado.
- Lotes editables, numeración de bultos, perfiles de empresa y temas claro/oscuro.
- Uso manual, importación de archivos locales e impresión sin internet.

**El idioma no cambia los documentos admitidos.** El lector actual admite NF-e brasileña de salida, modelo 55. No interpreta automáticamente facturas de otros países. Las leyendas impresas permanecen en portugués; nombres, direcciones y datos fiscales no se traducen.

## Empezar

1. [Descargue el paquete Windows](https://github.com/Gabs0078/etiquetas-expedicao-universal/releases/tag/v0.5.1), no “Source code”.
2. Extraiga todo el ZIP y abra **Instalar TagEX.exe**.
3. Instale, abra TagEX y elija importar XML, entrada manual o configurar carpetas.

Windows 10/11 x64. El paquete incluye Node.js y dependencias. El instalador aún no tiene firma digital ni actualización automática. Los paquetes Linux/macOS están previstos.

[Aplicación web](https://gabs0078.github.io/etiquetas-expedicao-universal/) · [Guía](https://gabs0078.github.io/etiquetas-expedicao-universal/instalar.html) · [Contribuir](CONTRIBUTING.md)
