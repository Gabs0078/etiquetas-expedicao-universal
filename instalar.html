Local app · Windows

Your labels, even offline.

Import XMLs, fill in labels and print on this computer. Searching company folders is optional.

Download TagEX for WindowsVersion 0.5.0 · 64-bit Windows 10/11 · Linux and macOS coming soon.
Internet is needed to download; you can then transfer the ZIP by USB drive.

Install in four steps

  1. Download the Windows packageUse the button above. On GitHub, download TagEX-Windows-0.5.0.zip from Releases; “Source code” is for developers.
  2. Extract all filesRight-click the ZIP and choose Extract all. Open the extracted folder; do not run the installer inside the ZIP.
  3. Open “Instalar TagEX.exe”Choose your language and click Install. Installation is for your account, with a Start menu shortcut and an optional desktop shortcut. Node.js and other components are included.
  4. Open TagEX and choose how to startStart with Import XMLs or enter manually, without configuring folders. To search company XMLs, choose Set up company folder search.

Then use the TagEX shortcut. The browser address 127.0.0.1:8788 points to this computer. The installer does not change printers, file shares or firewall settings.

The current XML reader supports Brazilian outgoing NF-e, model 55. Changing the language does not change the invoice format or translate invoice data; printed captions remain in Portuguese in this version.

Search company folders · optional

  1. Open “Set up integration”Find it under Search folders in the local app or in the TagEX tray icon beside the clock.
  2. Add the XML foldersSelect a local folder or paste a network path. Your Windows account must be able to open the folder.
  3. Review the test and saveAccessible folders can be saved even if empty or with warnings for some files. Keeping unavailable folders is optional, to retry when the network returns.
  4. Search and review the invoiceEnter an invoice number or customer and click the magnifier. Wait for initial indexing; later searches use the disk index. Starting with Windows is optional. Original XMLs are not modified.

What works offline?

  • Manual entry, local XML import, batch editing and printing work offline. The printer must be installed and available.
  • Local folders work offline while TagEX is running. Server folders need the company network or VPN; this is different from internet access.
  • The website caches the interface after a first visit, but the browser may clear it. The local package includes the interface and does not depend on that cache. The website cannot search folders on its own.

The website and local app have separate data. Companies, preferences and batches stay in the browser and address where they were created. Nothing is automatically transferred between Pages and 127.0.0.1; keep browser data if you need it.

If you need help

App will not open or is disconnected

Open the TagEX shortcut. Closing the tab keeps the service running; Exit in the tray stops it. An occupied port 8788 is reported without closing other programs. The last error is in %LOCALAPPDATA%\EtiquetasExpedicao\ultimo-erro.txt.

Windows blocked the installer

This release is not digitally signed. Check that it came from this repository. If company policy blocks it, contact IT; do not disable Windows protections.

How do I update?

Download the new package, extract all files, exit TagEX from the tray and run the new Instalar TagEX.exe. Folder settings and the index stay in %LOCALAPPDATA%\EtiquetasExpedicao. Use the same browser and address to retain batches and companies. Updates are manual.

Use without installing

In the extracted folder, open Abrir TagEX.exe. Keep the whole folder in a fixed location. This mode creates no shortcuts. If you move it, turn Windows startup off and on again in the wizard.

How do I uninstall?

Exit TagEX from the tray and use Windows Settings → Apps → TagEX → Uninstall. Settings, browser data and original XMLs are retained.
