# TagEX 0.5.1 — Approved visual identity

- The header now uses the complete TagEX wordmark based on Gabriel's Photoshop composition, with balanced internal cutouts in the lowercase a and g. The name appears once, as part of the logo.
- A simplified T inside a label is used for browser tabs, application icons, Windows tray, setup windows and launchers.
- Transparent SVG sources, PNG exports and a multi-resolution Windows ICO are included. `pnpm icons:build` regenerates the bitmap assets; the brand README documents their use.
- Windows executables embed the application icon. Packaging compiles the launcher without loading or locking the resulting executable before creating the ZIP.
- Updated the sharing image, offline cache and installation links for this release.

The uniform-stroke design remains an experimental mockup and is not included in the application. Invoice parsing, folder integration, label layouts and printed information are unchanged.

**Windows:** download **TagEX-Windows-0.5.1.zip**, extract the entire archive and open **Instalar TagEX.exe**. The runtime and XML parser are included. Updates remain manual; close TagEX from the tray before updating. Company settings, browser data and original XMLs are preserved.

**Português:** identidade visual aprovada aplicada ao cabeçalho, navegador e Windows, com os vãos internos do a/g simétricos. O pacote inclui a nova marca e mantém a integração e a impressão existentes. O estudo de traços uniformes não substitui a logo aprovada.
