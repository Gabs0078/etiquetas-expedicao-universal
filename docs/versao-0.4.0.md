# TagEX 0.4.0 — instalação local e uso offline

- Instalador Windows por usuário com atalho no menu Iniciar e opção de atalho na área de trabalho.
- Runtime Node.js 24 e parser XML incluídos: instalação offline sem dependências globais.
- Primeira abertura com escolha entre usar manual/XML ou configurar pastas.
- Guia no site, no GitHub e dentro do ZIP, com atualização, desinstalação e limites de funcionamento offline.
- Verificação de integridade antes de substituir o programa; configurações e dados externos à instalação preservados.

**Como começar:** baixe TagEX-Windows-0.4.0.zip, extraia tudo e abra Instalar TagEX.exe. Source code é destinado ao desenvolvimento e não inclui o runtime.

Windows 10/11 x64. O pacote ainda não possui assinatura digital ou atualização automática. Pastas de rede exigem acesso ao servidor da empresa. Dados do Pages e do endereço local são separados.
