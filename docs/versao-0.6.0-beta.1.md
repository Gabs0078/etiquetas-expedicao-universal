# TagEX 0.6.0-beta.1 — Freight report

This beta adds an A4 report for preparing freight quotes. It presents each invoice as a compact two-column list with invoice number, package count, gross weight, invoice value, recipient and package dimensions.

- Enter freight value and gross weight manually or import them from Brazilian NF-e XML.
- Enter one shared dimension set or enable separate dimensions for each package. The report calculates per-package and total cubic volume when the dimensions are complete.
- Leave the dimensions blank in the report to write them by hand.
- Package counts are zero-padded (01, 02, 03); weight uses at least two decimal places.

The report is an early release for feedback. Check the print preview and printer settings before using it for a freight quote. The existing label workflow remains available.

**Windows:** download **TagEX-Windows-0.6.0-beta.1.zip**, extract the complete archive and open **Instalar TagEX.exe**. The package includes the runtime and XML parser. Updates remain manual; close TagEX from the tray before updating. Company settings, browser data and original XML files are preserved.

**Português:** esta versão beta inclui relatório A4 para cotação de frete, medidas iguais ou diferentes por volume, cubagem automática e opção de deixar campos para preencher à caneta. Confira a prévia e as configurações da impressora antes de usar o relatório.
