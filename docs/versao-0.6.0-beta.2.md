# TagEX 0.6.0-beta.2 — Installer updates and vector branding

This beta adds a clearer Windows update flow and the approved TagEX vector identity.

- The installer detects an existing TagEX installation and compares its version with the downloaded package.
- When the package is newer, the installer shows both versions and asks before updating. Settings, folder integration and the local index are preserved.
- If the same version is already installed, the installer offers to open TagEX. It refuses to downgrade a newer installation.
- The application header and browser favicon use theme-matched SVG artwork in light and dark mode.
- The update package is still downloaded manually. The app does not check GitHub for releases.

**Windows:** download **TagEX-Windows-0.6.0-beta.2.zip**, extract the complete archive, exit TagEX from the system tray and open **Instalar TagEX.exe**. You do not need to uninstall first. The installer validates the package before replacing the app. Company settings, browser data and original XML files are preserved.

**Português:** o instalador agora compara a versão instalada com a versão do pacote baixado. Se o pacote for mais recente, mostra as versões e pede confirmação. Se já for a mesma versão, oferece abrir o TagEX; se o programa instalado for mais recente, não faz downgrade. As novas logos vetoriais mudam conforme o tema claro/escuro. O download do pacote continua manual.

This release also includes the A4 freight report introduced in beta.1.
