# Aplicativo TagEX para Windows

Para usar: [baixe o pacote Windows 0.4.0](https://github.com/Gabs0078/etiquetas-expedicao-universal/releases/download/v0.4.0/TagEX-Windows-0.4.0.zip), extraia tudo e abra **Instalar TagEX.exe**. O pacote inclui runtime e leitor XML. Não precisa de Node global nem comandos. Abra pelo atalho **TagEX**.

Na primeira abertura, escolha importar XMLs/preencher manualmente ou configurar as pastas. A configuração é opcional e pode ser feita depois. Para uso portátil, abra **Abrir TagEX.exe** na pasta extraída.

- [Instalação, offline, atualização e desinstalação](../docs/instalacao-windows.md)
- [Guia do usuário](../docs/guia-usuario.md)
- [Construção e validação do pacote](../docs/pacote-windows.md)

A versão ainda não possui assinatura digital nem atualizador automático. Driver, impressora, compartilhamento e firewall não são alterados.
