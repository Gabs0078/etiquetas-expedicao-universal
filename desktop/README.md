# Aplicativo Windows e assistente

Abra **Abrir Etiquetas.vbs**. O iniciador abre o serviço local e o navegador; a primeira configuração usa um assistente de quatro etapas. Para revisar pastas, use **Configurar integração** no aplicativo ou o menu do ícone ao lado do relógio.

- [Guia do usuário](../docs/guia-usuario.md)
- [Dependências, arquitetura, segurança e homologação](../docs/arquitetura-integracao.md)

O pacote deve incluir Node.js >=24 e o parser XML. A inicialização automática é opcional, por usuário. Driver e compartilhamento de impressão não são alterados. Distribuição atual por ZIP; instalação assinada e atualização automática ainda não implementadas.
